# 이미지와 저작권 확인

- 이번 회차 `assets/covers/` 의 표지 이미지는 담당자가 제공한 실제 판본 표지입니다. 지난 회차의 자체 제작 대체 이미지와 다릅니다.
- 공개 저장소에 게시하기 전에 표지 이미지의 이용 조건(출판사 제공 여부, 서점·API 이용약관, 기관 홍보 목적 사용 범위)을 확인하십시오.
- 소장 판본과 표지가 일치하는지 확인하십시오. 여러 권으로 이루어진 작품은 대표 1권의 표지만 사용했습니다.
- 책 표지 이미지 파일에는 독자 정보, 대출 정보 등 개인정보를 포함하지 마십시오.
- GitHub Pages는 공개 웹사이트이므로 내부 문서, 비공개 연락처, 승인 전 원고를 올리지 마십시오.
- 영화 제목·연도·감독 정보는 안내 목적의 사실 표기로만 사용하고, 영화 포스터나 스틸 이미지는 이 저장소에 올리지 않습니다.
